About DomainSentinel

What it does

DomainSentinel looks up public information about a website name and gives a risk score from 0 to 100. Every point of the score comes with a reason, so the result can be checked and explained.

How it works

  1. 1
    Enter a website name
    Only the name, like example.com.
  2. 2
    It checks public records
    Registration, address, email rules and server location.
  3. 3
    It adds up warning signs
    The score runs from 0 (safe) to 100 (very risky).
  4. 4
    You get a clear report
    Each point has a reason.

What it checks

  • Age of the name: brand new names are often used in scams.
  • Look-alike names: names that imitate famous brands, like paypa1.com.
  • Does it exist: whether the name points to a real server.
  • Email protection: whether fake emails can easily pretend to come from it.
  • Server location: which country and company run the server.

Words explained

WHOIS
The registration record of a website name: who registered it, when, and with which company.
DNS
The internet's address book. It tells which server a name points to.
SPF and DMARC
Email rules that help block or mark fake emails pretending to come from a website.
Look-alike domain
A name that imitates a famous brand with small changes, like g00gle.com.
Risk score
A number from 0 to 100 that adds up warning signs. It is a hint to look closer, not a final verdict.

Limits

  • The point values are my own choices, so the score is an indicator, not a verdict.
  • The look-alike check knows only 17 brands.
  • Free WHOIS and IP services can return empty data. The tool then shows it as unknown.
  • The tool is passive: it reads public records and never visits the scanned website.

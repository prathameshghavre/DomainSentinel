How it works

  1. 1
    Enter a website name
    Only the name, like example.com.
  2. 2
    It checks public records
    Registration, address, email rules and server location.
  3. 3
    It adds up warning signs
    The result is a score from 0 (safe) to 100 (very risky).
  4. 4
    You get a clear report
    Every point of the score comes with a reason.

What it checks

  • Age of the website name: brand new names are often used in scams.
  • Look-alike names: names that imitate famous brands, like paypa1.com.
  • Does it exist: whether the name points to a real server.
  • Email protection: whether fake emails can easily pretend to come from it.
  • Server location: which country and company run the server.
  • Input safety: only real website names are accepted, nothing else.

What do these words mean?

WHOIS
The registration record of a website name: who registered it, when, and with which company.
DNS
The internet's address book. It tells which server a website name points to.
SPF and DMARC
Email rules a website owner can set so that fake emails pretending to be from them are blocked or marked.
Look-alike domain
A name that imitates a famous brand with small changes, like g00gle.com or paypa1.com.
Risk score
A number from 0 to 100 that adds up warning signs. It is a hint to look closer, not a final verdict.
